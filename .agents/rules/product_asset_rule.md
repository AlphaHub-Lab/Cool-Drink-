# NO FILTER — PRODUCT ASSET RULE

NEVER place a generated square product scene directly into the animated website Hero.

A generated product scene containing:
- bottle
- table
- floor
- background
- fruit
- lighting
- environment

is NOT an acceptable Hero product asset.

For animated product experiences, separate:
1. PRODUCT
2. ENVIRONMENT
3. FRUIT
4. SHADOW
5. LIGHTING
6. ATMOSPHERE
7. TYPOGRAPHY

The product must be independently compositable.

==================================================
CANONICAL PRODUCT RULE
The No Filter bottle identity must remain consistent throughout the website.

AI image generation must NOT invent:
- brand names
- alternative bottle brands
- random labels
- random logos
- fake product names
- fake claims

The current No Filter branding must be preserved exactly.

If image generation cannot reliably reproduce the exact label, generate the bottle with a CLEAN / BLANK LABEL AREA and apply the real No Filter label separately.

==================================================
BOTTLE ASSET REQUIREMENT
Generate:
- ONE realistic bottle
- isolated
- full bottle visible
- transparent background if supported
- no table
- no floor
- no environment
- no surrounding fruit
- no decorative objects
- no background scenery
- no baked-in cast shadow
- no baked-in environment lighting

The bottle should look like professional beverage product photography.

The website will provide: environment, background, shadow, lighting treatment, parallax, animation, fruit, liquid effects.

==================================================
IMPORTANT
If transparent-background generation is unreliable:
Generate the bottle on a uniform solid background.
Then use a LOCAL background-removal/segmentation process before using the asset in the website.
Do not simply place the original square image into the page.

==================================================
ASSET QUALITY CHECK
Reject any generated bottle that:
- has the wrong brand
- has incorrect text
- has a random logo
- has malformed geometry
- includes a table/floor
- includes a background
- contains additional objects
- looks cartoon-like
- looks like a generic CGI stock render
- cannot be cleanly separated

Do not try to "fix" a fundamentally unsuitable generated image using CSS.
Regenerate the asset.
